# cargo-ai 0.4.1

## Secure credential input

- Add `cargo ai account confirm --stdin` for native clients. Launch the CLI directly, write the email confirmation code to a pipe, and close stdin. The positional code interface remains available; exactly one input source is required.
- Bound confirmation stdin to 1,024 raw bytes and profile-token stdin to 16,384 raw bytes, including trailing newlines. Both modes reject terminal input without prompting, accept trailing LF/CRLF, and reject empty, multiline, NUL or invalid UTF-8 input with redacted diagnostics.
- Keep confirmation codes and returned credentials out of confirmation output and error messages. Complete success requires both server confirmation and local credential/metadata persistence. If confirmation succeeds but local persistence fails, the command exits nonzero and explains that local setup remains incomplete. A transport failure may leave the server outcome unknown; follow the recovery guidance before retrying.
- Harden `cargo ai profile set <NAME> --stdin` and credential-storage diagnostics while retaining existing token-source interfaces, selected Cargo AI Home and credential backend. Invalid input is rejected before credential migration; valid updates preserve existing migration behavior.
- Preserve registration consent and account reactivation/deletion-cancellation behavior. Stdin is an input channel, not lifecycle consent.

## Guidance

- Clarify saved profile selection, separate provider and hosted-account access, and trusted-tool secret references. Runtime variables and model inputs are not a secret vault; a file reference does not guarantee exclusive access or prevent a tool from disclosing its contents.
- Correct installed guidance for package references, child-agent paths/log locations and supported workspace permissions.

This patch retains the 0.4.x definition and command compatibility line. Stdin callers must supply a pipe and close it; malformed or oversized profile input that previously reached storage now fails. See [account confirmation](../docs/accounts-and-sharing.md) and [provider profiles](../docs/providers/README.md#store-api-keys-safely) for the exact input, environment and failure contracts.

## Upgrade

```bash
cargo install cargo-ai --version 0.4.1
cargo ai version
```

Use the current stable Rust toolchain. The rolling unsigned Windows preview is separate from this versioned release. See [installation](../docs/install/README.md).
